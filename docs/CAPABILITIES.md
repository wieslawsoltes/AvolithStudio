# Avolith Studio 0.2 — capability matrix

Status describes implemented and tested behaviors, not whole-product parity. **Exact** means an OpenCascade analytic/tolerance-based B-rep, not symbolic arithmetic or unlimited robustness. Display meshes are approximations of exact geometry.

| Area | Implemented | Remaining limits / targets |
|---|---|---|
| Analytic modeling source | Serialized B-rep plus instance pose; analytic primitives, Boolean union/subtraction/intersection, splitting, cylindrical cuts, exact area/volume/centroid | Not a complete commercial modeling kernel interface; automatic design-intent recognition is absent |
| Exact curved surfaces | Weighted nonperiodic tensor-product B-splines; poles/degrees/distinct knots/multiplicities; solid/surface loft, revolution, circular-section sweep; open-face offset and thickening | Arbitrary trim-loop editor, periodic control nets, continuity networks, surface matching and patch healing are not implemented |
| Direct editing | Kernel fillet on selected/all edges; equal chamfer; remove-face shell; draft; planar face-prism Pull; rigid/uniform transforms and reflection | Variable-radius fillets, all corner-blend classes, unrestricted curved-face relocation, nonuniform B-rep affine edits, all offset self-intersections are not supported |
| Existing faceted tools | Original primitives, sketches, pull, Boolean, repair/reduction, layers/materials/components, measurements, local persistence and file exchange preserved | Faceted tools do not acquire analytic precision. Exact bodies require explicit conversion before mesh-only editing |
| Import/export | STEP, IGES, BREP analytic geometry; original STL/OBJ/PLY/DXF imports and STL/OBJ/GLB/DXF/SVG/CSV exports | Proprietary native CAD translators absent; STEP/IGES import does not preserve original assembly hierarchy, source feature history or semantic PMI; not all schema/entity combinations have been verified |
| IGES bridge | Isolated legacy OpenCascade worker, STEP AP203 bridge, analytic geometry roundtrip regression | Separate larger WASM download, geometry-only translation, no colors/hierarchy/PMI promise; legacy translator robustness is bounded |
| Native projects | Exact/faceted bodies, normals, portable B-rep, uniform pose, sheet definitions, mate datums, constraints and PMI; undo/redo and IndexedDB autosave | References use body-local frames plus topology-generation keys, not a universal persistent-naming algorithm |
| Developable sheet | Multiple signed bends, inside radii, constant width/thickness, tangent flange lengths, K-factor, round punches on flats, unfold/refold, SVG/DXF and bend CSV | Not arbitrary sheet branches, miter/relief automation, hems, beads, louvres, curved-flat outlines, deformable forming or springback; overlapping/tangent punches rejected |
| Sheet physical model | Analytic constant-thickness folded geometry; empirical neutral-axis bend allowance `abs(angleRadians)*(insideRadius + K*thickness)` | K other than 0.5 changes developed length relative to the mid-thickness geometric path. Folded/flat volume is not asserted invariant for that idealization; no strain simulation |
| Assembly mates | Coincident point, distance, parallel axis, axis angle, planar offset, point-on-plane, concentric, revolute, slider and fixed; datums, grounding, transactional solve, residual/rank/DOF | Local damped least-squares solver, not universal convergence; no dynamics, gears, collision-driven motion or full kinematic-path solver. Limits: 32 participating bodies, 100 mates |
| Drawing | Three native HLR orthographic views on A3, visible/hidden curves, title block, SVG; old wire drawing preserved for facets | No complete detailing/document management, section/hatch/auxiliary-view system, printing certification or production drawing standard conformance |
| Dimensions / PMI | Linear/angle/radius/diameter annotations with numeric tolerances; datum labels, notes, FCF characteristic/tolerance/material-condition/datum ordering; viewport display; semantic JSON | Geometric requirements are metadata, not measured/certified conformance. Limited FCF display styling, no full composite frames, datum-simulator semantics or semantic STEP-PMI exchange |
| Preparation | Exact native distance and common volume, external domain subtraction; topology, small-edge/face and stale-reference checks; sampled display-mesh walls; exact-aware BOM | No guaranteed minimum-thickness proof, automatic internal flow-volume recognition, tetrahedral/hexahedral meshing, solved FEA/CFD or manufacturing certification |
| Solver interchange | VTK POLYDATA with body groups; S3 shell skin with user section and material values | S3 is an explicitly chosen surface-shell idealization, NOT a volume-solid mesh. Loads, supports, contacts and analysis steps are not inferred |
| Renderer | Native WebGPU, 4× MSAA, shadows, smooth exact-surface normals, topological edge polylines, picking/BVH, GPU area/volume analysis | Physical-GPU benchmark/certification absent; WebGL2 and Canvas fallbacks remain explicitly labeled |
| Packaging | Enhanced HTTP(S) app with self-hosted replaceable CAD libraries; original-style dependency-free standalone faceted edition | Enhanced exact engine is not embedded in the standalone HTML |

## Reliability boundaries

Kernel results pass `BRepCheck_Analyzer` before committing. Explicit application budgets limit files, display tessellation, topology counts, NURBS control nets and queued work. Failed/cancelled/stale worker results do not replace the model. Kernel memory is scoped and released; terminating a worker releases its entire native heap. Native topology validity does not prove intended shape, engineering suitability or translator completeness.

The baseline source remains preserved in history. Missing targets above are not counted as complete merely because adjacent features or named ribbon groups are present.
