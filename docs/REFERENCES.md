# Public reference material

This project is original source code and original UI iconography. Public product documentation informed the familiar ribbon/direct-modeling workflow; it was not used as a source of proprietary code or assets. Avolith is not affiliated with the referenced vendors and does not claim file-format or API compatibility.

Public sources consulted during implementation (retrieved 2026-09-09):

- Official SpaceClaim product overview: https://ansys.synopsys.com/products/3d-design/ansys-spaceclaim
- Official interface documentation: https://ansyshelp.ansys.com/public/Views/Secured/corp/v251/en/spaceclaim/Discovery/user_manual/the_spaceclaim_interface.html
- Official historical interface documentation: https://help.spaceclaim.com/2015.0.0/en/Content/The_SpaceClaim_interface.htm
- W3C WebGPU Shading Language specification: https://www.w3.org/TR/WGSL/

The application uses an original name, original procedural examples and its own geometry/renderer implementation. Capability boundaries, not visual resemblance, determine what this release can actually do. See `CAPABILITIES.md` and executable tests.
